🔑 YouTube API key (for channels)
A free key lets Family TV read a channel's name, picture and video list, and check for new videos. Without one, only /channel/UC… and playlist links work, and they just play straight through.
  1. Go to console.cloud.google.com and sign in with a Google account.
  2. Create a project (any name, e.g. Family TV).
  3. Search for YouTube Data API v3 and tap Enable.
  4. Go to APIs & Services → Credentials → Create credentials → API key.
  5. Recommended: edit the key, choose Websites restriction and add https://YOURNAME.github.io/*.
  6. Copy the key and paste it below.
The key is saved in this browser only — it isn't in the page's code, so it stays off GitHub.
